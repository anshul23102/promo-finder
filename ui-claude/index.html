In this page, no install

Choose one episode (.txt) or a ZIP of episodes and get this same page for your show in seconds. The finder runs inside your browser, with no AI and no upload; your files never leave your computer.

Run on a script

On the command line

Rules only: no key, no AI, under a second for a whole show. Add a model to have it score and judge the cuts. Swap the model with one flag: gemini, groq, openrouter, ollama, or any OpenAI-compatible endpoint.

python3 -m promo path/to/scripts.zip

python3 -m promo path/to/scripts.zip \
  --model groq:openai/gpt-oss-120b \
  --judge groq:qwen/qwen3.8-27b --no-guide

What goes in

One text file per episode, or one ZIP of them. Each cue is a label, a time range and the text. ACTION, CAMERA and SOUND FX are understood; any other label is a speaker. The episode number comes from the file name (ep_3.txt, episode-003.txt) or an EPISODE NUMBER: line. A logline and continuity notes help but are optional.

**MAYA (stunned):**
Start: (00:02.29) | End: (00:05.17)
"H. Calloway. Our publisher signed your death."
