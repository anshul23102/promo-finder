Use it on a new show

Any show whose screenplay files carry timed cues works unchanged. Nothing here is specific to one story.

Fastest way: the workbench

Run one command, drop your episode files into the page that opens, pick an engine, and get a page like this one for your show. It all runs on your computer; your scripts are only sent anywhere if you pick an AI engine and confirm.

python3 ui-claude/workbench.py

What goes in

One text file per episode. Each cue is a label, a time range and the text:

**MAYA (stunned):**
Start: (00:02.29) | End: (00:05.17)
"H. Calloway. Our publisher signed your death."

Labels ACTION, CAMERA and SOUND FX are understood; any other label is a speaker. The episode number comes from the file name (ep_3.txt, episode-003.txt) or an EPISODE NUMBER: line. A logline and continuity notes help but are optional. Subtitle files (SRT, VTT) are not read yet.

Try it with no setup

Open the hosted app, upload a ZIP or a few episode files, and run it in rules mode. No key, no AI.

Use the hosted app only with scripts you are free to share. For confidential scripts, run it on your own machine.

Run it from the command line

python3 -m promo path/to/scripts.zip \
  --model groq:openai/gpt-oss-120b \
  --judge groq:qwen/qwen3.8-27b --no-guide

Swap the model with one flag (gemini, groq, openrouter, ollama, any OpenAI-compatible endpoint). --model rules needs no AI at all. Every answer is cached, so a re-run costs nothing.

View a finished run

python3 ui-claude/serve.py \
  --run private/runs/<your-run> \
  --pack path/to/scripts.zip

This builds this same interface for your show and serves it on your own computer only. Your scripts never leave it.

What you get back

For every promo: the episode and each segment's start and end in order, the hook, the cliffhanger, one line on why it works, and its place in the posting order. As files: promos.csv, promos.json, posting_plan.md, an editing list (cutlist.edl), a quality report and every raw model reply.

How this works

Promos is the answer: every promo the tool found, in the order to post them, with the hook, the cliffhanger and why it works. Review lets you watch one as the script plays, move its start and end, and mark Keep (post it), Trim (good, but move the cut points) or Pass.

Hide AI hints removes everything the AI thinks (rank, summaries, scores) and shuffles the order, so your rating is your own judgment. Use it when you want to check the tool against a person.
